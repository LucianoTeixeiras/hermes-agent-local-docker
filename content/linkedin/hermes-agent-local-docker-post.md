# LinkedIn Post - Hermes Agent Local Docker Starter Kit

## Publicacao principal

Agentes de IA locais so comecam a ficar realmente interessantes quando deixam de ser experimento solto e passam a ter um minimo de operacao: isolamento, configuracao reproduzivel, seguranca, documentacao e governanca.

Foi com esse objetivo que publiquei o **Hermes Agent Local Docker Starter Kit**.

O repositorio entrega uma base simples para rodar o Hermes Agent localmente com Docker, pensando em quem quer testar, estudar, adaptar ou iniciar uma operacao mais controlada com agentes.

O foco nao e complicar. E justamente o contrario:

- subir o Hermes com Docker Compose;
- manter dados e configuracoes persistentes;
- separar segredos do codigo;
- contemplar Windows, WSL, Linux e Ubuntu;
- documentar o uso tecnico sem perder a visao executiva;
- oferecer exemplos de `.env` e `config.yaml` para acelerar a configuracao.

Na pratica, e um starter kit para transformar curiosidade tecnica em ambiente minimamente governavel.

Deixei o detalhe tecnico dentro do proprio repositorio: scripts, Compose, exemplos, documentacao tecnica e documentacao executiva.

Repositorio:
https://github.com/LucianoTeixeiras/hermes-agent-local-docker

Se voce esta explorando agentes locais, Docker, automacao com LLMs ou formas mais seguras de experimentar esse tipo de stack, talvez esse projeto economize algumas horas do seu caminho.
